1.  In XAMPP Apache und MySQL starten.
2.  Inhalt der utf8mb4_general_ci.sql oder utf8mb4_0900_ai_ci.sql kopieren und in lokaler Datenbank ausführen.
3.  Die Website auf http://localhost/ aufrufen.
4.  Für den Kunden User:        Benutzername = KundenUser
                                Passwort = Start123!
    Für den Mitarbeiter User:   Benutzername = MitarbeiterUser
                                Passwort = Start123!
5. Zum wechseln des Nutzers "Ausloggen" auf dem Dashboard drücken.

Kunden:
Reservierung eines Liegeplatzes:
Ziehen Sie ihr gemietetes Boot auf den Liegeplatz mit dem Mauszeiger.
(Grün = Liegeplatz verfügbar; Blau = Eine Seite des Liegeplatzes belegt; Orange = Liegeplatz vollständig belegt)

Mieten eines Bootes:
Wählen Sie ihr gewünschtes Boot aus und füllen Sie das Formular aus.

Zahlungen:
Hier können Sie Ihre Zahlungen einsehen.

Einstellungen:
Hier können Sie Darkmode ein oder aus stellen und auf Ihre Accountdaten zugreifen und diese anpassen.

Ausloggen:
Der momentane User wird ausgeloggt.


Mitarbeiter:
Liegeplätze verwalten:
Hier können die einzelnen Liegeplätze verwaltet und die Daten und Reservierungen dieser angepasst werden.

Boote verwalten:
Hier können alle Boote eingesehen werden und die Daten und Vermietungen dieser angepasst werden.

Kunden verwalten:
Hier können Nutzerkonten eingesehen und die Daten dieser angepasst werden.

Einstellungen:
Hier können Sie Darkmode ein oder aus stellen.

Ausloggen:
Der momentane User wird ausgeloggt.
